# neuraeco — سایتِ معرفیِ نورا + سوپرادمین (برای اینماد)

سایتِ عمومیِ نورا **بدونِ ورود و خرید**، با سوپرادمین که همه‌چیز را تنظیم می‌کند.
بدونِ دیتابیس و بدونِ `npm install` — فقط Node.js (نسخهٔ ۱۸ یا بالاتر). محتوا در `data/content.json` ذخیره می‌شود.

## صفحات
`/` خانه · `/p/about` درباره ما · `/p/terms` قوانین و مقررات · `/p/privacy` حریم خصوصی · `/p/faq` پرسش‌های متداول · `/p/contact` تماس با ما
— در سوپرادمین هر صفحه ویرایش، حذف یا اضافه می‌شود.

## سوپرادمین: `/admin`
- **داشبورد:** بازدیدِ امروز/دیروز/۷ و ۳۰ روز، نمودارِ ۳۰ روز، پربازدیدترین صفحه‌ها (بدونِ کوکی، بدونِ ربات‌ها).
- **پیام‌ها:** صندوقِ فرمِ «ارسال پیام» (خوانده/خوانده‌نشده، حذف، جست‌وجو، خروجیِ اکسل) با نشانِ تعدادِ پیامِ تازه.
- **تنظیمات کلی:** هویت و سئو، تصویرِ اشتراک‌گذاری، نوارِ اطلاع‌رسانی، لینک‌های اضافهٔ منو و فوتر، دکمه‌های شناورِ واتساپ/تلگرام/تماس، صفحهٔ ۴۰۴، حالتِ تعمیر، کدهای اضافه.
- **اینماد و نمادها.**
- **ظاهر و گرافیک:** ۶ طرحِ آماده، **رنگِ لوگو** (رنگِ اصلی/یک رنگ/گرادیان + اندازه و متن)، رنگ‌ها، فونت، گوشه‌ها، دکمه‌ها، کارت‌ها، چیدمانِ صفحهٔ اصلی، favicon، CSSِ دلخواه، پیش‌نمایشِ زندهٔ دسکتاپ/موبایل.
- **صفحهٔ اصلی:** همهٔ متن‌ها و تصاویر، بخش‌های دلخواه، **ترتیبِ بخش‌ها**.
- **ایجنت‌ها، اطلاعات تماس** (+ فرمِ ارسال پیام).
- **صفحات:** فهرست، صفحهٔ جدید، کپی، ویرایشگر با نوارِ قالب‌بندی و پیش‌نمایش، تصویرِ بالای صفحه.
- **رسانه‌ها:** کتابخانهٔ تصاویر (بارگذاریِ چندتایی، انتخاب در هر فیلدِ تصویر، حذفِ امن).
- **حساب و پشتیبان:** تغییرِ رمز، دانلود/بازگردانی، **پشتیبانِ خودکارِ هر ذخیره** (۳۰ نسخهٔ آخر) با بازگردانیِ یک‌کلیکی.

`/sitemap.xml` و `/robots.txt` خودکار ساخته می‌شوند.

## نصب روی سرورِ خامِ Ubuntu (آروان)
```bash
sudo apt-get update && sudo apt-get install -y git
git clone https://github.com/aminjn/neuraeco.git && cd neuraeco
git checkout claude/nice-cray-khddi1          # تا وقتی در main ادغام نشده
sudo bash deploy/install.sh DOMAIN.ir admin 'رمز-قوی-حداقل-۸'
```
اسکریپت Node، nginx و سرویسِ systemdِ `neuraeco` را راه می‌اندازد. ریپو خصوصی است؟ آدرسِ clone را با توکن بزنید:
`https://TOKEN@github.com/aminjn/neuraeco.git`.

سپس در پنلِ آروان: دامنه را به CDN اضافه کنید، رکوردِ A را به IPِ سرور بدهید و HTTPS را روشن کنید.

به‌روزرسانی: `git pull && sudo bash deploy/update.sh` (محتوای ذخیره‌شده دست نمی‌خورد).
فراموشیِ رمز: `cd /opt/neuraeco && sudo -u neuraeco node server.js set-admin admin 'رمز-تازه'`

## برای اینماد
1. در «اطلاعات تماس» تلفنِ ثابت، نشانی و ایمیلِ **واقعیِ** پرونده را بگذارید (مقادیرِ فعلی نمونه‌اند).
2. «قوانین و مقررات» و «درباره ما» را با اطلاعاتِ کسب‌وکارِ خودتان مرور کنید.
3. پس از صدورِ نماد، کدش را در «اینماد و نمادها» بگذارید.
