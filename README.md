# neuraeco — صفحهٔ معرفیِ نورا (برای اینماد)

نسخهٔ **ایستا**ی صفحهٔ اولِ سایتِ عمومیِ نورا (از ریپوی Neurauidesign: `front/src/app/components/site-public.tsx`)،
با همان CSS، فونت، تصاویر و محتوا — اما **بدونِ ورود، قیمت، خرید و دستیارِ گفتگو**. هیچ درخواستِ API یا CDN ندارد.

## انتشار
کلِ پوشه را روی هر وب‌سرورِ ایستا (nginx/هاستِ اشتراکی) بگذارید؛ `index.html` صفحهٔ اصلی است.

## پیش از درخواستِ اینماد
- اطلاعاتِ تماس (تلفن، نشانی، ایمیل، شناسهٔ ملی) فعلاً همان متنِ پیش‌فرضِ سایت است — باید با اطلاعاتِ
  **واقعیِ** ثبت‌شده در اینماد یکی شود. در `index.html` بخش‌های `#contact` و فوتر را ویرایش کنید.
- کدِ نمادِ اینماد را داخلِ `<div class="enamad" data-enamad>` در فوتر بگذارید.
- اگر اینماد متای تأیید داد، در `<head>` جای کامنتِ مربوط بگذارید.

## ساختِ دوباره
`tools/build-home.mjs` همین `index.html` را از `server/src/site-content-default.js`ِ Neurauidesign می‌سازد
(مسیرِ ریپو داخلِ اسکریپت است).
